## What's new since v3.1.0

- **Supply chain you can audit:** SBOM per release, SLSA-style attestations,
  signed checksums — rare among small Firefox forks.
- **Distribution:** winget 3-file manifests (`manifests/winget/Can5.FoxAIBrowser/3.2.0/`)
  ready for winget-pkgs PR; Flatpak manifest on Freedesktop 24.08 runtime
  (`manifests/flatpak/`) with `.desktop` + Metainfo.
- **Site:** animated download page (`download.html`), `privacy.html` policy page,
  AI story unified to opt-in (device-local default, per-action Allow).
- **Policy:** `SECURITY.md` (48h ack / 90-day coordinated) + RFC 9116 `security.txt`.
