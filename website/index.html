What FoxAI is built on

No dark magic. A real browser engine, standard extension APIs, and a build pipeline that is fully reproducible from source.

🦊 Firefox ESR 140.13.0

The engine itself — a stable, extended-support release of Firefox, rebranded as "FoxAI Browser" (name, icon and version strings via rcedit). It stays portable: unzip and run.

🧩 Four WebExtensions (MV2)

New-tab, AI sidebar, search & gestures are all standard WebExtensions installed through policies.json, so they can't be disabled or tampered with by sites.

⚛️ React + Vite

The FoxAI Start new-tab is a small React app built with Vite — fast, type-safe, and shipped as plain static assets with a strict CSP.

🛠️ PowerShell build pipeline

build.ps1 reproduces everything from source: packages XPIs, downloads uBlock, brands the binaries, writes policy files, creates a fresh profile and a release zip.

🧪 WebDriver BiDi test suite

Five end-to-end tests drive a real headless browser over the BiDi protocol and verify the new-tab, persistence, search default, settings and the AI sidebar.

📦 Nothing on your system

No installer, no services, no registry changes, no background updaters. The whole browser lives in one folder you can delete at any time.

Why it exists

The short version: browsers collect too much, show you too little, and add features you never asked for. FoxAI is the opposite.

💥 It began with a deletion

The original project was accidentally wiped. FoxAI was rebuilt from a ~7,000-file salvage backup — and during the rebuild, every default a browser sneaks in (telemetry, autofill, prefetch, referrers) was questioned and, where it leaks, turned off.

🔬 Verifiable, not just "trust us"

Each release ships a changelog that lists the exact leak that was closed and how. You can read it, rebuild it from source, and run the test suite yourself. There is nothing to take on faith.

🏡 For daily use, not for show

Privacy is useless if the browser is painful. FoxAI keeps the features people actually use — notes, to-do, bookmarks, quick search, AI help, mouse gestures — without the ones that exist to harvest you.

The AI that waits for permission

Nothing runs in the background. Page content is shared only when you click "Allow page access", one action at a time — and you can revoke it instantly.

  • ChatGPT, Claude, Gemini or keyless local Ollama
  • Free chat sends no page data
  • Extraction capped and consent-gated
  • API keys stored locally, never in URLs or logs

Privacy you can verify

  • No telemetry, no data collection
  • Referrer disabled, beacon & ping disabled
  • First-party isolation on
  • Prefetch / predictor / DNS prefetch off
  • Autofill & form history off
  • Camera / microphone disabled by default
  • Weather is opt-in (no location by default)
  • Content scripts only run inside the browser
  • Strict CSP: no inline script, no iframing
  • Punycode shown for spoofed-looking domains
  • Only the sites you visit, ever contacted
  • Every fix is in the changelog, every line is local

Who made it

A one-person project. No company, no analytics, no sign-ups — just a developer who wanted a browser with no hidden listeners.

FoxAI — solo developer project

Designed, built, tested and maintained by one person. Every commit is public, every design decision is documented in the changelog, and the entire source can be rebuilt with a single command. The name says it: Fox — for the Firefox engine it rides on, and AI — for the assistant that sits beside you, only when asked.
