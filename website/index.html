The AI that waits for permission

Nothing runs in the background. Page content is shared only when you click "Allow page access", one action at a time — and you can revoke it instantly.

  • ChatGPT, Claude, Gemini or keyless local Ollama
  • Free chat sends no page data
  • Extraction capped and consent-gated
  • API keys stored locally, never in URLs or logs

Privacy you can verify

  • No telemetry, no data collection
  • Referrer disabled, beacon & ping disabled
  • First-party isolation on
  • Prefetch / predictor / DNS prefetch off
  • Autofill & form history off
  • Camera / microphone disabled by default
  • Weather is opt-in (no location by default)
  • Content scripts only run inside the browser
  • Strict CSP: no inline script, no iframing
  • Punycode shown for spoofed-looking domains
  • Only the sites you visit, ever contacted
  • Every fix is in the changelog, every line is local
